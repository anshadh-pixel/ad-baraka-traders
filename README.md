# 🚀 BizFlow Pro

> **Smart Business & Customer-Specific Rate Management Web App with WhatsApp Billing & Offline Local Storage**

## Features
- 🏷️ **Different Rates for Different Customers:** Set customized negotiated prices for each customer under each product.
- 📱 **100% Mobile Optimized:** No zoom glitch, no accidental bounce, native bottom dock navigation, safe area support.
- 💾 **Phone Local Storage:** Works offline, saves directly to browser local storage with 1-click JSON backup export/restore.
- 🧾 **Direct WhatsApp Invoicing:** Formats and sends itemized bills with balance dues directly to customers on WhatsApp.
- 📅 **Date Setup:** Track order date, delivery schedule, and payment collection dates.
- ✨ **Ultra-Modern UI & Animations:** Glassmorphism, fintech theme, spring modals, and celebratory confetti.

## Running the App
```bash
npm install
npm run dev
```

Open `http://localhost:5173` on PC or `http://172.20.10.2:5173` on Phone.
